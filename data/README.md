# Local data directory

This public repository does not redistribute RoadStar-provided source files, generated
scenario indexes, operational identifiers, or runtime artifacts.

For an authorized local run, place the event workbook at
`data/Hackathon_Data.xlsx` and the locally generated scenario index at
`data/indexed_scenarios.json`. You may instead set `ROADSTAR_DATASET_PATH` and
`ROADSTAR_SCENARIO_INDEX_PATH` to paths outside this repository.

Do not commit either file unless the organizer or data owner explicitly grants
redistribution rights.
